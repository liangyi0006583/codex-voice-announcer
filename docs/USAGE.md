Codex 语音播报使用说明

双击桌面应用打开控制窗口。关闭或退出窗口，后台仍继续运行。

暂停播报：停止当前语音，继续记录事件。恢复后不自动朗读暂停期间的积压内容，可手动重播。
测试声音：用当前音色、语速和语气播报测试文字。
停止当前朗读：取消正在生成或播放的音频，并清空当前播报队列。
重新连接：重启本工具后台，不修改 Codex 任务。
打开对应任务：在 Codex 中打开当前选中的聊天。

默认使用系统中文女声。守望者、红皇后、蓝染参考片段已随安装附带，需先安装可选本地模型后选择使用。另有三组自定义参考音色，可通过项目导入工具添加自己的音频与逐字稿。

系统和自定义音色均可调节语速与音调。自定义音色播放中调节速度、音调和语气会改变播放器效果；句间停顿变化在下一条合成生效。系统音色设置在下一条播报生效。

语气有清晰正式、柔和自然、沉稳坚定。它们调整音调、节奏和已有停顿，不支持任意情绪指令。

自定义语音需要先完整准备再播放，长内容等待时间更久。准备与播放均可停止。模型在准备完成后释放，空闲时不常驻。

声音跟随 Mac 默认输出。输出切换后会重新配置播放器，短暂等待后继续。程序不修改系统音量。静音、休眠或没有可用输出设备时无法听到。

每条内容最多朗读约 500 字；完整结果请打开任务查看。同一事件去重，人工请求优先于普通完成结果。启动时会补播本机现有未读结果。

运行数据仅在本机用户目录 Library/Application Support/CodexVoiceAnnouncer 内。此目录包含任务标题、内容和线程标识，不要公开上传。

使用内部 Codex 桌面接口，应用升级后可能需要适配。无法连接或读取时会显示错误。本工具不会批准请求、修改任务、标记已读或上传文本与音频。

朗读稳定性：长正文按句分批合成，完成后连续播放。每批语音会核对实际语言及内容，错误或重复输出使用系统中文备用播报。播放中断不会自动从头重复。
临时音频在正常完成、停止及可处理的异常退出后清理；强制杀进程或崩溃可能留下残留。显式导出试听、用户参考文件、素材和模型不会自动删除。

# 隐私边界与公开内容

## 仓库内容

仅包含通用源码、构建 / 安装 / 卸载工具、文档和人工构造的测试。不存在真实聊天、线程 ID、商品编号、用户路径、私有账号配置、声音样本或模型权重。

公开项目采用通用服务名称和动态用户目录。提交使用 GitHub noreply 地址，避免提交者的私人邮箱进入提交记录。

## 本机访问

后台通过本机 Unix socket 订阅 Codex 桌面事件，读取本机任务目录、未读状态及完成记录。SQLite 连接使用只读模式，不读取 `auth.json`、Keychain 或 API 密钥。它不会启动新任务、代替用户回答、批准请求或改写 Codex 数据。

语音播放后仍保留最近 200 条提醒，包含任务标题、可读内容、线程标识及时间。状态文件也包含当前任务标题和状态；去重记录可保存较多事件哈希。服务日志记录运行错误。以上均属于用户本机数据，不应公开上传。

运行目录权限为 0700，JSON 和日志在私有 umask 下写入，文件权限为 0600。没有 HTTP 服务、遥测或云端推理。

## 脱敏的限制

播报文本和持久历史会去除常见 API 密钥、Bearer token、JWT 形态，以及带密码 / 密钥字段标签的值；原始命令输出和推理内容不播报。运行时识别不是完整数据防泄漏方案，普通姓名、商业数据或不符合规则的敏感文字仍可能保留在历史或错误日志中。

分享问题报告时仅复制必要的脱敏错误和版本信息，不上传整个运行目录、Codex 数据库、参考音频或认证文件。

## 网络边界

基础版不需要网络访问。本地模型推理开启 Hugging Face / Transformers 离线模式；任务文本和参考音频不发送给语音服务。

可选安装工具通过 pip 下载依赖，通过 Hugging Face 下载固定公开模型版本。这些安装下载会产生普通网络请求，不包含任务文本或参考音频，不读取认证令牌。

不通过禁用系统安全设置安装；项目不要求密码或 API 密钥。游戏、电影原声等第三方素材由用户自行确认使用许可，仓库不提供此类素材。
